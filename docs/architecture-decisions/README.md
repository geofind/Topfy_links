# Architecture Decision Records (ADR)

Toda vez que se decidir implementar algo próprio em vez de reutilizar uma solução madura (Skill, MCP, SDK, API oficial, biblioteca, template, componente existente — ver ordem em [`../ARCHITECTURE.md`](../ARCHITECTURE.md)), registre um ADR aqui usando [`_TEMPLATE.md`](_TEMPLATE.md).

Nomeie o arquivo `NNNN-titulo-curto.md`, sequencial a partir de `0001`.

Sem ADR, uma implementação própria não deve ser considerada concluída (ver checklist em [`../../AGENTS.md`](../../AGENTS.md)).
